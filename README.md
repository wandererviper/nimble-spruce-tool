# nimble-spruce-tool



学习用的示例项目

## 用法

```bash
cat data.txt | python main.py
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

就是给自己省点事，没做太多抽象。

## 安装

```bash
git clone https://github.com/USER/nimble-spruce-tool.git
cd nimble-spruce-tool
pip install -r requirements.txt
```
